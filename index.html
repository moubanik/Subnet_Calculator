Subnet Calculator

Subnetting Formulas:

1. Number of Networks:
2^n (n = borrowed bits)

2. Hosts per Network:
2^h - 2 (h = host bits)

3. Block Size:
2^h

4. CIDR:
32 - log2(Block Size)

5. Subnet Mask:
CIDR → Dotted Decimal

6. Network Address:
IP AND Subnet Mask

7. Broadcast Address:
Network + Block Size - 1

8. First Host:
Network + 1

9. Last Host:
Broadcast - 1
